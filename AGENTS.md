# AGENTS.md — правила работы ИИ-агентов в этом проекте

## Обязательно перед началом работы
1. Прочитай `.ai/context.md` — текущее состояние проекта.
2. Прочитай последние 2–3 записи в `.ai/journal.md` — не повторяй уже сделанное.

## Обязательно после работы
1. Добавь запись в `.ai/journal.md` (шаблон: `.ai/templates/journal-entry.md`).
2. Обнови `.ai/context.md` (статус, следующие шаги).
3. Если принято важное решение (выбор библиотеки, архитектуры) — запиши его в `.ai/decisions.md`.

## Формат записи журнала
Дата, агент, что сделано, какие файлы изменены, что не доделано, как проверить.
Кратко, по-русски, без воды.

## Правила кода
- Коммиты: conventional commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Не коммитить секреты: токен бота — только в `.env` (`.env` в `.gitignore`).
- Каждый рабочий день бота = рабочий коммит.
- Ветки: `feat/<название>` для фич, `fix/<название>` для багфиксов.
